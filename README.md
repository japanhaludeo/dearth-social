# DearthSocial

DearthSocialのアカウント登録・ログイン・ログアウト・パスワード変更・アカウント完全削除、および投稿・返信機能です。

## 必要環境

- Node.js 20以上
- npm

## 起動方法

```bash
npm install
npm start
```

ブラウザで <http://localhost:3000> を開いてください。

開発中の自動再起動:

```bash
npm run dev
```

## 機能

- アカウント作成（アカウント名、アカウントID、パスワード）
- アカウントIDは英数字と`_`のみ、2～30文字。大文字入力は小文字に変換し、ハイフンは不可
- アカウントIDの重複チェック（アカウント名は重複可能）
- パスワードは2～72文字
- ログイン・ログアウト
- パスワード変更（現在のパスワードを確認後、既存セッションを無効化）
- アカウント完全削除（確認後にアカウント、投稿、返信を削除）
- 投稿（全角2・半角1文字換算で256文字まで）
- 返信（全角2・半角1文字換算で64文字まで）
- タイムラインに最新50件の投稿を表示し、各投稿の返信を表示

## セキュリティ

- bcryptによるパスワードハッシュ化
- HTTPOnly・SameSite Cookieセッション（本番環境ではSecure属性）
- セッションごとのCSRFトークン
- 入力バリデーション
- 書き込み操作への簡易レート制限

本番環境では `SESSION_SECRET` を固定した十分に長いランダム値に設定し、HTTPSを有効にしてください。

```bash
SESSION_SECRET='長いランダム文字列' NODE_ENV=production npm start
```

アカウント情報は実行ディレクトリの `data.sqlite` に保存されます。データベースファイルはリポジトリにコミットしないでください。
